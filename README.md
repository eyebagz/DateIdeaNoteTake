# Our Date Journal

A simple date idea journal built with HTML, CSS and JavaScript. It keeps plans in one place with a clean, muted scrapbook-inspired look, subtle paper textures, and restrained motion.

## Features
- A required title, with optional location, planned date, start time, estimated cost in GBP, description, things to bring and notes.
- Separate **To Be Completed** and **Completed** sections.
- View details, edit, delete, mark as completed, and move dates back to To Be Completed.
- Muted slate navy, dusty teal, sage, warm cream and stone accents. Light mode only.
- Responsive desktop and mobile layout, keyboard focus styles, and reduced-motion support.
- No account, server, database, or build tools required.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Add date ideas and use the card actions to manage them.

## Files
- `index.html` — page structure and dialogs
- `css/style.css` — colours, layout, animation and responsive styles
- `js/app.js` — form validation, local storage, rendering, editing, completion and details

## Saving note
Date ideas are stored in this browser's local storage on this device. They do not automatically sync to another device or browser. Clearing browser site data may remove them.
