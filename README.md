Date Note Journal Book thing (I need to think of a better name I know chillax)
A chill little date idea journal to keep all your plans organized in one cute, scrapbook-inspired spot.

Heads Up
I built the HTML, CSS, and the whole design myself! However, I was totally struggling with JavaScript, so I had an AI help me write the JS code for this project. Everything else is 100% my work.

Features
All the details: Add titles, locations, times, costs in GBP, descriptions, and things to bring.

Two sections: Easily switch between To Be Completed and Completed dates.

Aesthetic look: Muted slate navy, dusty teal, sage, and warm cream (light mode only).

Zero setup: No servers, databases, or build tools needed—it just runs.

How to Run It
Unzip the folder.

Double-click index.html to open it in your browser.

Add some dates and manage your plans!

(Quick note: Your date ideas are saved in your browser's local storage on your device, so clearing your site data will wipe them!)
